Overview

What the C++ edition actually is.

A working game engine built around software rasterization. No hardware acceleration required. Runs on Linux today, with Windows and macOS on the development path.

Architecture

How it's built.

The C++ edition is organized around a small number of focused subsystems. Each is a real implementation, tested and shipped.

C++ Edition — Top-level architecture

Luma Engine C++

  ├── Editor // Dear ImGui + docking

  ├── Runtime // Main loop, 60 FPS

  │   ├── LOVE VM // Scripting

  │   ├── Scene Graph // Nodes + transforms

  │   ├── Input Manager // SDL3

  │   └── Audio System // SDL3

  ├── Dimension_L // Rendering

  │   ├── Rasterizer // Software

  │   ├── Render Graph // Passes

  │   └── DL-V1 // Camera + viewport

  └── Assets // AssetManager

Features

What works today.

Everything in this section is implemented and tested. Nothing here is a roadmap promise.

Runtime Loop

  • 60 FPS continuous execution
  • Delta time tracking
  • Play / Pause / Stop
  • 100 instructions per frame

LOVE Scripting

  • Bytecode compilation
  • Stack-based VM
  • Variables and control flow
  • Keyboard and mouse input

Software Renderer

  • Framebuffer with Z-buffer
  • Pixel, line, triangle, rect, circle
  • Color management
  • Dimension_L architecture

Integrated Editor

  • LOVE Language IDE
  • Syntax highlighting
  • File and asset browser
  • Docking support

Scene System

  • Node hierarchy with transforms
  • SpriteNode with textures
  • ShapeNode for primitives
  • Viewport rendering

Audio

  • SDL3 audio backend
  • WAV loading
  • Playback control
  • Master volume
