Changelog

What changed in Luma Engine.

Every notable change to the engine, the DL-ARA Rust workspace, and the launcher. Kept honest: features that are still research-grade stay in the Not Implemented section until they ship.

unreleased current working tree In Progress

Everything in this entry is in the working tree but has not been tagged as a release. When the workspace is tagged v0.1.0, this block will be renamed and a new empty unreleased block will be added above it.

dl-math

Added

  • Full scalar math foundation (MathConstants, clamp, lerp, smoothstep, waves, approx_eq, move_towards, approach).
  • bits: next_power_of_two, is_power_of_two, bit_reverse_u32, byte_swap_*, splitmix64_finalize, hash_2d.
  • angle: wrap_positive, wrap_signed, difference, lerp, move_towards.
  • random: split-mix deterministic RNG, thread-local RNG.
  • fastmath: fast_exp, fast_log, fast_pow, fast_inv_sqrt, fast_sin, fast_cos. Each documented with valid input range, measured error, and whether the standard library version is faster.
  • vector: plain #[repr(C)] structs, no SIMD. Vec2 = 8 bytes, Vec3 = 12, Vec4 = 16. Hand-written reverse scalar multiply impls. Bit-identical Hash impls.
  • color: HSV, luminance, ACES / Reinhard / Filmic / Uncharted 2 tonemapping, gamma, effects, blend modes, RGB565 / ARGB1555 / RGBA1010102 / RGBE / half-float packing.
  • matrix: Mat4 in column-major flat [f32; 16]. perspective and orthographic use [0, 1] clip depth. inverse and look_at return Option.
  • quaternion: Hamilton multiplication, from_axis_angle, from_euler, slerp (handles antipodal), rotate, to_mat4.
  • geometry: Aabb, Ray, Plane, Frustum, Rect, Viewport. is_point_in_triangle fixed (inclusive boundary).
  • fixed: Fixed<IntType, FRACTIONAL_BITS>. sqrt uses bit-by-bit isqrt. From<f32> saturates; try_from_f64 returns Option.
  • noise: perlin_2d, value_noise_2d, simplex_2d, fbm_2d, ridged_noise_2d. Bit-identical to the C++.
  • CONVENTIONS.md: right-handed, column-major, column-vectors, −Z forward, [0, 1] clip depth, radians.

dl-rendergraph

Added

  • Image (RGBA8, row-major, top-left origin).
  • RenderGraph with target registry, pass list, execution loop, Presenter trait.
  • GridPass: infinite neon grid, evaluated analytically per pixel. Ray-plane intersection in f64, world-space distance-to-line with pixel-footprint floor, smoothstep AA, distance fade.

dl-render-pass

Added

  • RenderPass, PassDescriptor, PassType, PassContext, ResourceAccess, ResourceType, AccessMode, PassError.

dl-render-camera

Added

  • Viewport, Projection (perspective + orthographic, [0, 1] depth).
  • ViewMatrix::look_at in f64 (downcast to f32).
  • Frustum six-plane extraction (Gribb-Hartmann, [0, 1] adapted).

dl-input

Added

  • Key, MouseButton (Left, Right, Middle, X1, X2, X3, X4), MouseAxis, GamepadButton, GamepadAxis, ControllerType (Xbox, PlayStation, Nintendo).
  • GamepadButton::from_platform(controller, physical_face).
  • InputEvent, InputBinding with scale / inverted / deadzone.
  • InputAction with radial deadzone (rescale), vector2 clamping.
  • ActionMap with WASD and arrow-key helpers.

dl-render-graph-compile

Added

  • RAW / WAR / WAW edge extraction.
  • Kahn's cycle detection returning the set of passes in the cycle.
  • Stable topological sort.
  • Validation, CompiledGraph, PassRunner dispatch.

dl-rasterization

Added

  • SubpixelCoord (8 fractional bits, 1 pixel = 256 units).
  • Watertight EdgeEquations with incremental step_x / step_y, top-left fill rule.
  • DepthBuffer with standard and reversed Z.
  • SerialRasterizer and TiledRasterizer. tiled_matches_serial_coverage test proves bit-identical output.
  • TileScheduler — deterministic multithreaded dispatch. parallel_matches_serial test proves bit-identical output.
  • criterion benchmark comparing serial, tiled, and parallel.

dl-ray

Added

  • Ray with precomputed inv_direction.
  • Hit with front_face and prim_id for O(1) material lookup.
  • Watertight Möller–Trumbore ray-triangle intersection.
  • Analytic primitives: Plane, Sphere, Disk, Cylinder, Cone.
  • Transform with precomputed inverse and inverse-transpose.
  • Binned SAH BVH: build, iterative traversal with explicit stack, refit for dynamic meshes.
  • Scene with automatic Acceleration::{None, Bvh} selection.

dl-ray-tracing

Added

  • Reference-correct PCG32 with per-pixel-per-frame seeding for TAA. Reference test checks the paper's published sequence.
  • Sampling: hemisphere-uniform, cosine, sphere-uniform, GGX reflection. Each has a Monte Carlo PDF integration test.
  • Bsdf trait, Lambertian, Mirror, Dielectric (verified ~4% reflectance at normal incidence into glass), Emissive.
  • PointLight, DirectionalLight, AreaLight (uniform triangle sampling).
  • Path tracer with NEE, Russian roulette, power heuristic MIS on both sides.
  • Temporal accumulation, à-trous edge-aware denoiser driven by depth and normal.
  • ACES / Reinhard / Clamp tonemapping, sRGB encode, PPM writer.
  • render_realtime — trace → temporal → denoise → tonemap → sRGB → u8 pipeline.

luma_launcher

Added

  • Updater (GitHub Releases API, semver), UpdateWorker (background thread).
  • EngineLauncher (rename-away swap aware, Unix process group), LaunchManager (SIGTERM → SIGKILL grace period).
  • ProjectScanner, ProjectCreator, Templates (blank / 2D / 3D), Persistence (atomic state file), LumaPaths.
  • Sakura-pink UI shell with hero, sidebar, topbar, project cards, update bell, create-project flow.
  • Background download pipeline: DownloadWorker, EnginePaths, sha256_file, .tar.gz / .zip extraction, -old rename swap, chmod +x on Unix.

Changed

  • Vec3 is 12 bytes, not 16. The C++ Vec3T was 16 because of an __m128 union member. Documented in CONVENTIONS.md §7.1.
  • perspective / orthographic use [0, 1] clip depth. Required by wgpu; documented in CONVENTIONS.md §5.
  • Mat4::inverse and look_at return Option instead of producing identity or NaN.
  • Fixed::sqrt uses bit-by-bit isqrt.
  • Palette::get returns Option<&Color>.
  • MouseButton extended with X3 and X4. GamepadButton gains ControllerType and from_platform.

Fixed

  • is_point_in_triangle — the C++ applied Sign() to only the first term. Rust uses the standard three-half-plane test with an inclusive boundary.
  • is_power_of_two(0) — the C++ returned 0 from NextPowerOfTwo(0). Rust returns 1.
  • ReverseBits — the C++ DLMath::ReverseBits actually called __builtin_bswap32 (a byte swap, not a bit reversal). Rust provides both correctly.
  • Mat4 scalar multiply sign — the C++ had a transposed indexing pattern under one interpretation of the storage convention.

Removed

  • Empty module declarations removed from dl-ray (path_tracing, materials, lights, denoising, temporal, shadows, reflections, ambient_occlusion, monte_carlo, sampling, simd, dispatch, parallel, ray_query). These are real modules in dl-ray-tracing or dl-rendergraph.

Not Implemented

The following modules appear in the dl-ray-tracing file tree on disk but do not exist in lib.rs because they would be stubs. They will be added to lib.rs in the batch that gives them real code, not before.

bidirectional, photon_mapping, reservoir, volumetrics, spectral, subsurface_scattering, bssrdf, caustics, adaptive_sampling, simd.

Known Limitations

The real-time path tracer does not yet hit 60 / 45 / 30 fps at 720p / 1080p / 1440p on current hardware. The architecture is correct (1 spp, temporal, denoise, tile-parallel); tuning remains.

TemporalAccumulator does not yet reproject for a moving camera. Stationary camera is correct.
