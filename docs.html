The LOVE Language

Lightweight, sandboxed, and designed for game logic. LOVE runs on the Luma Engine VM with a runtime loop at 60 FPS. Fully integrated with the Scene System and Renderer.

Introduction

LOVE (Luma Object & Virtual-machine Environment) is a lightweight, sandboxed scripting language designed for the Luma Engine. It compiles to bytecode and runs on the Luma VM at 60 FPS within the engine's runtime loop.

Simple

Learn it in minutes

Sandboxed

Fast

Status: LOVE is fully integrated with the engine's Scene System, Renderer, and InputManager. All features documented here are working in the current build.

Getting Started

LOVE scripts are written in .love files and executed via the LOVE VM. The runtime loop handles continuous execution at 60 FPS.

Variables

let score 0
let x 433
let y 285

Basic Game Loop

// Basic LOVE game loop
loop
    color 20 20 40
    clear
    // Game logic here
    present
end

Variables

Declaration

let x 10
let name "Luma"
let is_running 1 // Boolean: 0 = false, 1 = true

Assignment

set x 20
get x // Push x onto stack
get y
add // x + y

Note: Variables are dynamically typed. The VM handles integer, float, string, and boolean types.

Operators

Arithmetic

get x
get y
add // x + y
sub // x - y
mul // x * y
div // x / y

Comparison

get x
get y
eq // x == y
ne // x != y
lt // x < y
gt // x > y
le // x <= y
ge // x >= y

Logical

and // Logical AND
or // Logical OR
not // Logical NOT

Control Flow

Loop

// Infinite game loop
loop
    color 20 20 40
    clear
    // Game logic here
    present
end

Unconditional Jump

jump my_label
// Code here is skipped
my_label:
// Execution continues here

Conditional Jump

get x
push_int 100
gt // x > 100 ?
jump_if label // Jump if true
// Code here runs if false
label:
// Code here runs if true

Tip: Labels can be any name and are resolved during compilation.

Input

LOVE provides direct access to keyboard and mouse input through the InputManager.

Keyboard

key_down "w" // Push true if W is pressed
key_down "space" // Push true if Space is pressed
key_down "a" // Push true if A is pressed

Mouse

mouse_x // Push mouse X position (in pixels)
mouse_y // Push mouse Y position (in pixels)
mouse_clicked // Push true if left mouse clicked this frame

Note: Input is polled at 60 FPS. key_down checks if the key is currently held down.

Rendering

LOVE scripts can draw primitives directly to the framebuffer using the software renderer.

Primitives

color 255 0 0 // Set color (R G B)
clear // Clear screen with current color
draw_pixel 100 100 // Draw a single pixel
draw_line 0 0 100 100 // Draw a line
draw_rect 100 100 50 50 // Draw rectangle outline
fill_rect 100 100 50 50 // Draw filled rectangle
draw_triangle 0 0 50 100 100 0 // Draw triangle outline
fill_triangle 0 0 50 100 100 0 // Draw filled triangle
draw_circle 433 285 25 // Draw circle outline
fill_circle 433 285 25 // Draw filled circle
present // Show the frame

Note: All coordinates are in pixels. The renderer uses a software framebuffer with Z-buffer support.

Examples

Bouncing Ball with Controls

// Bouncing ball with WASD control
let x 433
let y 285
let dx 3
let dy 2
let radius 25
let score 0

loop
    // Clear screen
    color 20 20 40
    clear
    
    // Move ball
    get x
    get dx
    add
    set x
    
    get y
    get dy
    add
    set y
    
    // Bounce off walls
    get x
    get radius
    lt
    jump_if bounce_x
    
    get x
    push_int 800
    get radius
    sub
    gt
    jump_if bounce_x
    
    // Draw ball
    color 74 255 0
    get x
    get y
    get radius
    fill_circle
    
    present
end

bounce_x:
push_int -1
get dx
mul
set dx
get score
push_int 1
add
set score
jump loop
